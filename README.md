# PCA Image Compression

Rank-k principal components approximations of four images. The page shows the
compression function, the approximation error for every rank, the first
eigenvector and first PC score of each image with an interpretation, and the
rank I would choose for each image.

Published with GitHub Pages from the `docs/` folder.

## Rebuilding

Place `image1.csv` through `image4.csv` in `docs/` beside `index.Rmd`, open
`index.Rmd` in RStudio, and knit. Requires `rmarkdown`, `knitr`, and `readr`.
